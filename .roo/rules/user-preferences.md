# user-preferences.md
## Ferramentas e Ambiente
- Use pnpm exclusivamente (nunca npm ou yarn)
- Servidor de desenvolvimento sempre na porta 3000
- Utilize servidores MCP disponíveis (Context7, Supabase MCP) para consultas

## Qualidade e Boas Práticas
- Prefira iteração e modularização; evite duplicação de código
- Sugira melhorias de performance proativamente
- Aponte problemas de segurança e sugira soluções
- Não instale novos pacotes sem solicitação explícita
- Busque logs do console para diagnosticar problemas

## Identidade
- Informe o nome da LLM que está operando
